📖 วิธีการใช้งานโปรแกรมตรวจสอบจุดอ่อน (How-to Guide)

1. ตรวจสอบจากลิงก์เว็บไซต์ / Apps Script

วาง URL เว็บไซต์ (เช่น https://... หรือลิงก์ Google Apps Script /exec) ในแท็บ 1 แล้วกด 🌐 ตรวจสอบลิงก์เว็บไซต์ ระบบจะตรวจ HTTPS, โครงสร้าง HTML/JS และสิทธิ์ Apps Script ให้อัตโนมัติ

2. ตรวจสอบโฟลเดอร์หรือไฟล์โค้ด

เลือกแท็บ 2 แล้วกด 📁 เลือกโฟลเดอร์โปรเจกต์... หรือ 📄 เลือกไฟล์โค้ด... (หรือกดปุ่ม Demo เพื่อทดลอง) ระบบสแกนในเบราว์เซอร์ 100% ไม่ส่งโค้ดออกจากเครื่อง

3. วางโค้ดจาก Apps Script Editor

สำหรับ Google Apps Script เลือกแท็บ 3 เลือกชนิดไฟล์ (Code.gs, index.html, appsscript.json) แล้ววางโค้ดเพื่อตรวจหาจุดอ่อนเชิงลึกทีละบรรทัด

4. สั่ง AI แก้ & เปรียบเทียบผล

หลังสแกนเสร็จ กด 📋 คัดลอก AI Prompt ไปวางใน ChatGPT / Claude / Gemini เพื่อรับโค้ดที่ปลอดภัย แล้วนำมาสแกนซ้ำและกด ⚖️ เปรียบเทียบกับผลปัจจุบัน ในส่วนประวัติเพื่อดูคะแนนที่เพิ่มขึ้น
ตรวจสอบครบทั้ง Security Headers, HTTPS/HSTS, Cookie Flags, CORS, โครงสร้าง HTML, โค้ด JavaScript หน้าบ้าน, และถอดรหัสหน้าเว็บ Google Apps Script (goog.script.init / google.script.run) อัตโนมัติ
สแกนในเบราว์เซอร์ 100% ไม่ส่งโค้ดออกจากเครื่อง • รองรับ .py, .gs (Apps Script), .js, .ts, .jsx, .tsx, .html, .php, .env, appsscript.json, requirements.txt, package.json, Dockerfile
เหมาะสำหรับโปรเจกต์ Google Apps Script ที่อยู่บน Google Drive / script.google.com โดยไม่ต้องดาวน์โหลดไฟล์ลงเครื่อง
